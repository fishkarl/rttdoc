Voice to Text RESTful API V3 Documentation

Version 7.x | New Version, Recommended⭐️

1. Overview

This document provides an overview of Agora's Voice to Text RESTful API. You can send HTTP requests from your business server to Agora's server to perform voice-to-text conversion on the server side. This product supports four modes:

  1. Real-time Captions: Only performs real-time voice-to-text functionality.
  2. Real-time Captions + Recording Captions: Based on real-time voice-to-text functionality, supports storing and playback of recognized text and video.
  3. Real-time Captions + Translation Captions: Based on real-time voice-to-text functionality, supports translating the recognized content, for example, real-time recognition of Chinese and translating it to English, then pushing both Chinese and English captions back to RTC.
  4. Real-time Captions + Recording Captions + Translation Captions: Based on real-time voice-to-text functionality, supports storing and playback of recognized text and video, while also supporting translation of recognized content, for example, real-time recognition of Chinese and translating it to English, then pushing both Chinese and English captions back to RTC.

1.1 Call Steps

The steps for voice-to-text conversion are as follows:

  1. Start a voice-to-text task through a join request.
  2. After completion, call leave to stop the voice-to-text task.

After starting voice-to-text conversion, you can also query the status of the voice-to-text task through a query request.

1.3 Limitations

The voice-to-text business is undergoing rapid iteration. If you encounter any issues during use, please contact service personnel directly to quickly identify the problem.

1.4 Additional Notes

The current version supports int type uid, but for future expansion to string type uid, the uid input in the Body is of string type, and will be automatically converted to int internally. In the future, 'enable_string_uid' will be added to allow users to choose the uid type.

2. Quick Start

Overall configuration parameter description:

  • gateway address is the gateway address provided by Agora.
  • appId is the App ID of your Agora project created on Agora Console.
  • taskId is the value of the taskId field returned after a successful start call by the business.

2.1 join

2.1.1 URL

https://api.agora.io/api/speech-to-text/v1/projects/{appid}/join

// trans-ai-agent

Note: The HTTP method for join call is POST.

2.1.2 Body

  • Request Body example and field explanation 
    {
  "languages": [                                  // Array of language codes for transcription, e.g., "en-US", "zh-CN"
      "<YourTranscribeLanguages>"
  ],
  "name": "xxxx",                                 // Task name for identification purposes
  "uidLanguagesConfig": [                        // Optional: Configure specific languages for individual users
     {
        "uid": "<YouSpecifyUid>",              // User ID to configure language for
        "languages": ["<YourTranscribeLanguages>"] // Languages to use for this specific user
     }
  ],
  "maxIdleTime": 50,                             // Maximum idle time in seconds before auto-termination
  "rtcConfig": {                                 // RTC configuration settings
      "channelName": "<YourChannelName>",       // Name of the RTC channel to join
      "subBotUid": "<YourSubscribeUid>",        // UID for the bot that subscribes to audio
      "subBotToken": "<YourSubscribeToken>",    // Token for the subscribing bot (optional)
      "pubBotUid": "<YourPublishUid>",          // UID for the bot that publishes captions
      "pubBotToken": "<YourPublishToken>",      // Token for the publishing bot (optional)
      "cryptionMode": <YourDecryptionMode>,     // Encryption mode if channel is encrypted
      "secret": "<YourSecret>",                 // Secret key for encryption
      "salt": "<YourSalt>",                     // Salt value for encryption
      "subscribeAudioUids": ["<YourSubscribeAudioUids>"],     // Specific UIDs to subscribe to
      "unSubscribeAudioUids": ["<YourUnSubscribeAudioUids>"], // UIDs to exclude from subscription
      "enableJsonProtocol": bool                 // Whether to enable JSON protocol
  },
  "captionConfig": {                             // Configuration for caption recording
      "sliceDuration": 60,                       // Duration of each caption slice in seconds
      "storage": {                               // Storage configuration for saving captions
          "accessKey": "<YourOssAccessKey>",    // Access key for the storage service
          "secretKey": "<YourOssSecretKey>",    // Secret key for the storage service
          "bucket": "<YourOssBucketName>",      // Bucket name for storing files
          "vendor": <YourOssVendor>,            // Storage vendor ID (e.g., 1=AWS, 2=Aliyun)
          "region": <YourOssRegion>,            // Storage region code
          "fileNamePrefix": ["<YourOssPrefix>"]  // Prefix for stored file names
      }
  },
  "translateConfig": {                           // Configuration for translation service
      "languages": [                             // Array of translation language pairs
          {
              "source": "<SourceLanguage>",      // Source language code (e.g., "zh-CN")
              "target": ["<TargetLanguage>"]     // Array of target language codes (e.g., ["en-US", "ja-JP"])
          }
      ]
  },
  "extensionParams": {                           // Optional extension parameters
      "<YourSessCtrlCfgName>": "<YourSessCtrCfgValue>"  // Custom configuration parameters
  }
}

    Note:

    <YourTranscribeLanguages>, <YourChannelName>, <YourSubscribeUid>, <YourSubscribeToken>, <YourPublishUid>, <YourPublishToken>, <YourToken>, <YourChannelType>, <YourOssAccessKey>, <YourOssSecretKey>, <YourOssBucketName>, <YourOssVendor>, <YourOssRegion>, <YourOssPrefix> etc. are fields that need to be replaced during testing.

    Parameter Description:

    uidLanguagesConfig Single Element Type Definition
    Parameter Type Required Description
    uid string Yes User ID to specify language for
    languages array Yes Array of language codes for transcription
    rtcConfig Type Definition
    Parameter Type Required Description
    channelName string Yes Name of the RTC channel
    subBotUid string Yes User ID for the subscription bot
    subBotToken string No Token for the subscription bot
    pubBotUid string Yes User ID for the publishing bot
    pubBotToken string No Token for the publishing bot
    cryptionMode integer No Encryption mode
    secret string No Secret for encryption
    salt string No Salt for encryption
    subscribeAudioUids array No List of user IDs to subscribe to
    unSubscribeAudioUids array No List of user IDs to unsubscribe from
    enableJsonProtocol boolean No Whether to enable JSON protocol
    captionConfig Type Definition
    Parameter Type Required Description
    sliceDuration integer Yes Duration of each caption slice in seconds
    storage object Yes Storage configuration for captions
    storage Type Definition
    Parameter Type Required Description
    accessKey string Yes Access key for the storage service
    secretKey string Yes Secret key for the storage service
    bucket string Yes Bucket name for storage
    vendor integer Yes Storage vendor identifier (e.g., 1=AWS, 2=Aliyun)
    region integer Yes Storage region identifier
    fileNamePrefix array No Prefix for stored files
    translateConfig Type Definition
    Parameter Type Required Description
    languages array Yes Array of language translation configurations
    enable boolean No Whether to enable translation
    languages Type Definition
    Parameter Type Required Description
    source string Yes Source language code
    target array Yes Array of target language codes

    Below is a body example using Real-time Captions + Recording Captions + Translation Captions, which can be used after replacing fields as needed:

    {

              "source": "zh-CN",                // Source language: Chinese

                  "fr-FR",                      // French
                  "ja-JP"                       // Japanese
              ]
          }
      ]
  },
  "captionConfig": {                            // Caption recording configuration
      "sliceDuration": 60,                      // Each recording slice is 60 seconds
      "storage": {                              // Storage configuration
          "accessKey": "test-oss",              // Storage access key
          "secretKey": "test-oss",              // Storage secret key
          "bucket": "test-oss",                 // Storage bucket name
          "vendor": 2,                          // Storage vendor (2 = Aliyun OSS)

      }
  }
}
  • Response Body
    • Success 
      {
 "agent_id": "String",     // Unique identifier for the created task

2.4 update

2.4.1 URL

Note: The HTTP method for update call is POST.

https://api.agora.io/api/speech-to-text/v1/projects/{appid}/agents/{agentId}/update

2.4.2 Body

  • Request Body 
    {
  "languages": [                                 // Update the transcription languages
      "<YourTranscribeLanguages>"
  ],
  "uidLanguagesConfig": [                        // Update language settings for specific users
     {
        "uid": "<YouSpecifyUid>",              // User ID to update settings for
        "languages": ["<YourTranscribeLanguages>"] // New languages for this user
     }
  ],
  "rtcConfig": {                                  // Update RTC configuration
      "subscribeAudioUids": ["123"]              // New list of UIDs to subscribe to
  },
  "translateConfig": {                            // Update translation settings
  "enable": true,                            // Enable/disable translation
  "languages": [                             // Update translation language pairs
      {
          "source": "<SourceLanguage>",      // Source language code
          "target": ["<TargetLanguage>"]     // Target language codes
      }
  ]
}
}

    Parameter Description:

    • Path: &sequenceId=1&updateMask=languages
    • Body: supported fields
    Field Description
    languages Update the transcription languages
    uidLanguagesConfig Update the language configuration for specific UIDs
    rtcConfig.subscribeAudioUids Update the list of UIDs to subscribe to
    translateConfig Update the translation configuration
