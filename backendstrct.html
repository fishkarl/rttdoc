Agora RTT Demo Server Documentation

Server integration with Agora's Real-Time Translation (RTT) service, providing speech-to-text and AI translation capabilities

Project Overview

Agora RTT Demo Server is a demonstration project that showcases the integration of Agora's Real-Time Translation (RTT) service, providing speech-to-text and AI translation capabilities. The project is built using Go, offering RESTful API endpoints and supporting Cross-Origin Resource Sharing (CORS).

Core Features:
  • Real-time speech-to-text conversion
  • AI-powered translation
  • RESTful API endpoints
  • Configurable logging
  • Cross-Origin Resource Sharing (CORS) support

Technology Stack

  • Programming Language: Go 1.20+
  • Build Tool: Make
  • Configuration Management: TOML
  • API Style: RESTful
  • Third-party Service: Agora RTT Service

Core Module Analysis

Configuration Management

The server uses TOML configuration files to manage various settings:

  • Log Configuration: Controls logging behavior, including file paths, log levels, and output modes
  • HTTP Server Configuration: Defines server port and other HTTP-related settings
  • Agora RTT Service Configuration: Contains API endpoints and authentication details

API Endpoints

The server exposes several RESTful endpoints for interacting with the Agora RTT service:

  • Join Endpoint: Creates a new speech-to-text agent
  • Leave Endpoint: Terminates an existing agent
  • Update Endpoint: Modifies agent settings
  • Info Endpoint: Retrieves agent information
  • Health Check: Monitors server status

Error Handling

The server implements comprehensive error handling:

  • Structured logging of all errors
  • Appropriate HTTP status codes for different error types
  • Consistent error response format

Security Features

Security is a key consideration in the server design:

  • CORS configuration for controlled cross-origin access
  • Authentication using Agora credentials
  • HTTPS support for production deployments
  • Input validation to prevent injection attacks

Configuration Details

Configuration File Structure

[log]
fileName = "/data/logs/server.log"  # Log file path
level = "INFO"                      # Log level (DEBUG, INFO, WARN, ERROR)
maxSize = 10                        # Max log file size in MB
mode = 0                            # Log mode (0: console, 1: file, 2: both)

[httpServer]
port = 8084                         # HTTP server port

[transAIServiceConfig]
baseURL = "https://api.agora.io"    # Agora API base URL

[transAIAppIdConfigs.your_app_id]
appCert = "<your_app_certificate>"  # Your Agora app certificate
appId = "<your_app_id>"             # Your Agora app ID
authPassword = "<your_auth_password>" # Console Customer Secret
authUsername = "<your_auth_username>" # Console Customer Key

API Endpoint Details

Speech-to-Text Endpoints

  • POST /v1/speech-to-text/projects/:appId/join

    Creates a new speech-to-text agent for the specified application.

  • POST /v1/speech-to-text/projects/:appId/agents/:agentId/leave

    Terminates an existing speech-to-text agent.

  • POST /v1/speech-to-text/projects/:appId/agents/:agentId/update

    Updates the settings of an existing speech-to-text agent.

  • POST /v1/speech-to-text/projects/:appId/agents/:agentId

    Retrieves information about an existing speech-to-text agent.

Health Check Endpoint

  • GET /healthz

    Returns the current status of the server. Used for monitoring and load balancing.

Development and Build Commands

  • make build: Builds the server application
  • make run: Runs the server on port 8084
  • make test: Runs the test suite
  • make clean: Cleans build artifacts

Prerequisites

  • Go 1.20 or higher
  • Make (for building)
  • Agora account and credentials
