Agora RTT Demo Project Structure

Note: This documentation is based on the Agora-RTT-Demo repository, specifically the feat/nsus/web branch.

1. Project Overview

Agora RTT (Real-Time Transcription) Demo is a sample project showcasing real-time speech-to-text functionality, built on Agora's real-time communication technology. The project implements features such as real-time speech transcription, multi-language support, and real-time translation.

2. Technology Stack

  • Frontend Framework: React.js
  • UI Components: Material-UI
  • State Management: React Context API
  • Real-time Communication: Agora RTC SDK
  • Real-time Transcription: Agora RTT SDK
  • Build Tool: Webpack

4. Core Components

RTTComponent.jsx

The core component for RTT functionality, responsible for initializing Agora RTC and RTT services, handling audio input, and transcription output.

Main Functions:

  • Initialize and manage Agora clients
  • Handle audio device selection
  • Start and stop transcription services
  • Process transcription results

TranscriptDisplay.jsx

Component responsible for displaying real-time transcription results.

Main Functions:

  • Display original transcription text
  • Show translation results (if enabled)
  • Handle display formatting for different languages
  • Support text copying and exporting

LanguageSelector.jsx

Language selection component that allows users to select source language and target translation language.

Main Functions:

  • Provide list of supported languages
  • Handle language switching events
  • Update RTT service language settings

5. Service Layer

agoraRTCService.js

Service layer encapsulating the Agora RTC SDK, handling real-time audio communication.

Main Functions:

  • Initialize RTC client
  • Join/leave channel
  • Audio device management
  • Volume control

agoraRTTService.js

Service layer encapsulating Agora RTT functionality, handling real-time transcription.

Main Functions:

  • Initialize RTT service
  • Configure transcription parameters
  • Handle transcription result callbacks
  • Manage transcription state
  • Process translation requests

7. Key Workflows

7.1 Initialization Flow

  1. The application starts and loads configuration from config.js
  2. Token Controller generates necessary tokens for Agora services
  3. RTT Component initializes the Agora RTC client
  4. Audio devices are enumerated and set up
  5. RTT service is initialized with selected language parameters

7.2 Transcription Flow

  1. User starts transcription through UI
  2. RTT Component activates audio capture
  3. Audio data is sent to Agora RTC SDK
  4. Agora RTT SDK processes the audio and returns transcription
  5. Transcription results are processed and formatted
  6. Results are displayed in the TranscriptDisplay component

7.3 Translation Flow

  1. User selects target language for translation
  2. Original transcription is sent to translation service
  3. Translation results are returned
  4. Both original and translated text are displayed in parallel

8. Configuration

The application requires the following configuration parameters in config.js:

Parameter Description
AGORA_APP_ID Agora application ID from Agora Console
AGORA_TOKEN Token for authentication (or token generation parameters)
DEFAULT_CHANNEL Default channel name for RTC connection
DEFAULT_SOURCE_LANGUAGE Default language for transcription
SUPPORTED_LANGUAGES Array of supported languages for transcription and translation

9. Getting Started

9.1 Prerequisites

  • Node.js (v14 or higher)
  • npm or yarn
  • Agora account with App ID and valid token

9.2 Installation

# Clone the repository
git clone https://github.com/AgoraIO-Community/Agora-RTT-Demo.git
cd Agora-RTT-Demo/web

# Install dependencies
npm install

# Configure the application
# Create a config.js file based on config.example.js
# Add your Agora App ID and token

# Start the development server
npm start

10. Customization Points

The application provides several customization points:

  • Language Support: Add or modify supported languages in the language utilities
  • UI Customization: Modify Material-UI themes and component styles
  • Transcription Display: Customize how transcriptions are formatted and displayed
  • Audio Processing: Adjust audio capture and processing parameters
Development Note: When extending this project, it's recommended to follow the established architecture pattern of separating UI components from service layers to maintain clean separation of concerns.
