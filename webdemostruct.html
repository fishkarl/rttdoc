Agora RTT Demo Project Documentation

Real-Time Translation demonstration application based on Agora SDK, supporting speech-to-text and real-time text translation functions

Project Overview

Agora RTT (Real-Time Translation) Demo is a real-time translation demonstration application based on Agora SDK, supporting speech-to-text and real-time text translation functions. The project is built using React + TypeScript, with Redux for state management and Ant Design as the UI component library.

Core Features:
  • Real-time audio and video communication
  • Speech-to-Text (STT)
  • Real-time text translation
  • Multi-language support

Technology Stack

  • Frontend Framework: React + TypeScript
  • State Management: Redux/Redux Toolkit
  • UI Components: Ant Design
  • Real-time Communication: Agora SDK (agora-rtc-sdk-ng, agora-rtm)
  • Internationalization: i18next
  • Data Serialization: Protobuf
  • Build Tool: Vite

Core Module Analysis

Entry Files

  • web/src/main.tsx: Application entry point, configuring Redux, Ant Design theme, and i18n internationalization
  • web/src/App.tsx: Main application component, containing the router container

Router Structure

  • web/src/router/index.tsx: Defines application routes, including home page, login page, and 404 page

State Management

  • web/src/store/index.ts: Redux store configuration, using Redux Toolkit
  • web/src/store/reducers/global.ts: Global state handling, containing user information, subtitle data, language settings, and other states

Business Logic Managers

  • web/src/manager/rtc/: Agora real-time communication management
  • web/src/manager/rtm/: Real-time messaging management
  • web/src/manager/stt/: Speech recognition and conversion module
  • web/src/manager/parser/: Data parsing module

Main Components

  • web/src/components/header/: Header component
  • web/src/components/footer/: Footer control bar component
  • web/src/components/caption/: Subtitle display component
  • web/src/components/dialog/: Dialog component
  • web/src/components/user-list/: User list component
  • web/src/components/menu/: Menu component
  • web/src/components/stream-player/: Media stream player component

Page Components

  • web/src/pages/home/: Home page
  • web/src/pages/login/: Login page
  • web/src/pages/404/: 404 error page

Frontend Data Flow

User Login Process

  1. User enters information on the login page
  2. Data is submitted to the store through Redux actions
  3. Data is stored in Redux's global.userInfo
  4. Simultaneously saved to local storage through setUserInfoToLocal

Real-time Audio and Video Communication

  1. The manager/rtc module handles interaction with the Agora RTC SDK
  2. Audio and video states are updated to the store through Redux actions
  3. Components retrieve states from Redux and render accordingly

Speech-to-Text and Translation Process

  1. Voice input is processed by the manager/stt module
  2. Speech recognition results are updated to the store through Redux actions (such as pushSubtitles)
  3. The subtitle component reads sttSubtitles data from the store and displays it

User Interaction and UI State Management

  1. User interactions trigger Redux actions
  2. Actions update states in the store (such as menuList, memberListShow, etc.)
  3. Components respond to state changes and re-render
