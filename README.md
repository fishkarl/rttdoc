# Agora Real-time Translation Best Practice

This repository contains documentation and examples for implementing real-time translation functionality using Agora's SDK and services.

## Overview

The Agora Real-time Translation Best Practice provides comprehensive documentation and implementation examples for building applications with real-time voice translation capabilities. This solution allows users speaking different languages to communicate without barriers by automatically translating voice content into the target language displayed as subtitles.

## Contents

- **Architecture Documentation**: Detailed explanation of the system architecture, workflow, and implementation steps
- **API Documentation**: Comprehensive guide for the Voice to Text RESTful API
- **Web Demo Structure**: Example implementation of a web-based real-time translation application
- **Best Practices**: Guidelines and recommendations for optimal implementation

## Key Features

- Real-time voice recognition and translation
- Multi-language support
- Seamless integration with Agora RTC and RTM SDKs
- Scalable architecture for handling multiple users
- Support for both web and server-side implementations

## Getting Started

1. Register for an Agora developer account
2. Create an Agora project and obtain an App ID
3. Turn on Agora STT service from the Agora console
4. Integrate Agora RTC and RTM SDK into your application
5. Follow the implementation steps in the architecture documentation

## Documentation

- [Architecture Documentation](architecture.html) - System overview, workflow, and implementation steps
- [Voice to Text API Documentation](asrv3.html) - Detailed API reference

## Requirements

- Agora Developer Account
- Agora App ID
- Supported browsers or platforms (for web implementation)
- Node.js (for server implementation)
